# Project Scope

Recall Radar is a local-only MVP for a US product recall search and SEO website.

## Current Scope

- Brand: Recall Radar
- Project: `recall-radar-web`
- Folder: `C:\Users\pc\codex-projects\recall-radar-web`
- Framework: Astro + TypeScript
- Port: `5179`
- Data: local mock TypeScript data and local JSON-ready folders
- Pages: home, checker, category pages, recall detail pages, and brand pages

## Explicitly Out Of Scope

- Real official recall data ingestion
- Databases
- External API calls
- Remote services
- Deployments
- Docker
- Git remotes
- Real secret files
- Email delivery or subscriber storage

## Future Development

Future official data sources may include CPSC, FDA/openFDA, USDA FSIS, and NHTSA. Add those only after this local-only scope is reviewed and a new step explicitly authorizes external data work.
